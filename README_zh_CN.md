## 💡 为什么需要“标签管家”？

在个人知识管理（PKM / 第二大脑）的实践中，**双向链接**像神经元突触一样构建微观的穿透网，而**标签（Tags）**则是横跨笔记本与知识领域的宏观分类坐标与多维切片工具。

然而，随着笔记数量与标签资产的日积月累，思源笔记原生的标签体验常常让用户陷入诸多困扰与心智负担：

| 日常使用场景 | 遇到的实际困惑与痛点 | 标签管家带来的解决方案与价值 |
| :--- | :--- | :--- |
| **随手记笔记打标** | 经常记不清曾建过什么标签；大小写敏感导致 `Prompt` 与 `prompt`、`Python` 与 `python` 并存割裂，甚至同一概念写出 `web-dev` 与 `web_dev` 等排版变体。 | **拼音首字母模糊联想**；**自动化冲突检测**与一键规范化合并，原名称自动沉淀为别名，随手怎么搜都搜得到。 |
| **翻阅与检索笔记** | 点击正文中的标签时，强行弹出一个全屏或半屏的全局搜索大窗口，瞬间遮挡当前正在阅读的文字，严重打断思路心流。 | **右侧抽屉式即时卡片流**，不弹大窗、不遮正文；点击卡片平滑滚动并高亮定位，沉浸流畅。 |
| **复杂专题知识切片** | 想找“*既属于 `#Vue3#` 又属于 `#架构#`，或者包含 `#React#`，但坚决排除 `#已废弃#`*”的内容，原生操作必须手写复杂多表 SQL。 | **可视化 `AND` / `OR` / `NOT` 三态布尔条件池**，点选即可完成多维度交叉知识切片。 |
| **批量整理与归档** | 整理课题或导入外部资料时，几十篇甚至上百篇文档需要归类，只能一篇篇手动点开打标，机械耗时。 | **原生文档树多选右键直达** + **交互式多源选择器**，支持勾选“包含子文档”，整本笔记本秒级完成批量打标。 |
| **双链与标签孤岛** | 正文里大量引用了 `((Vue 3 核心原理))` 等概念双链，但在标签管理视角下，这些文档完全游离在知识分类树之外。 | **引用智能识别为同名标签（Ref to Tag）**，自动分析双链锚文本、文档标题、命名与别名，一键采纳打标。 |
| **标签库长期维护** | 标签列表堆积了成百上千个仅用过一次的废弃标签或零引用标签，形成沉重的“标签债务”，想整理却不知从何下手。 | **知识库健康体检仪表盘（100分制）**，一键体检大小写冲突、标点变体、异常符号与孤儿标签，批量智能治理。 |

## ✨ 核心功能与真实使用场景

### 1. 🗂️ 标签全景资产树：极速定位与常用标签组
> **解决问题**：标签层级深、数量庞大时查找困难，频繁输入固定组合标签极度费手。

- **拼音首字母与别名模糊盲打**：
  - 无论标签是中文、英文还是中英混合，无需切换输入法。
  - 输入 `ytb` 瞬间匹配 `#YouTube#`，输入 `wz` 秒级命中 `#微服务#`，输入 `ff` 直达 `#方法论#`。
- **层级路径折叠与实时引用统计**：
  - 清晰呈现多层嵌套标签树（如 `#技术/前端/Vue#`），精确标注每个节点及其子树的实时引用总数。
  - 支持按**引用频次降序/升序**、**拼音字母 A-Z / Z-A** 随心切换排序。
- **🏷️ 常用标签组（Tag Groups）一键套用**：
  - 将高频搭配的标签组合封装为预设套件（如【前端核心栈：`vue`, `typescript`, `vite`】、【深度阅读：`读书笔记`, `认知科学`, `心智模型`】）。
  - **一键极速套用**：点击侧栏标签组旁的“套用”，立即为当前正在编辑的文档批量写入思源原生 IAL tags 属性，**绝不插入正文杂乱字符，保持笔记排版纯净**。

```
[日常打标] ──> 在侧栏点击「套用」常用标签组 ──> 1 秒完成当前文档多标签归档，正文零污染
```

---

### 2. ⚡ 多维交叉筛选与即时卡片流：非侵入式知识切片
> **解决问题**：告别粗暴弹出的全屏搜索窗口，轻松实现“交集/并集/差集”的跨维度深度检索。

- **可视化三态布尔逻辑（AND / OR / NOT）**：
  - 🟢 **AND（必含）**：必须同时具备的所有核心主题交集；
  - 🟡 **OR（可选）**：命中其中任一主题即可的并集扩展；
  - 🔴 **NOT（排除）**：精准剔除干扰信息（如排除 `#草稿#`、`#已归档#`、`#废弃#`）。
  - 仅需鼠标轻点，即可在三态间无缝轮转切换。
- **筛选池内拼音与关键词即搜即加**：
  - 面对庞大的标签库，无需在长列表中翻找，直接在多维筛选池顶部搜索框输入拼音，一键将目标标签加入筛选条件。
- **抽屉式即时卡片流**：
  - 搜索结果以精炼卡片形式在右侧抽屉直接呈现，完整显示上下文摘要与文档归属。
  - **零跳出阅读**：点击任意卡片，平滑滚动至正文目标块并伴随优雅的高亮提示，阅读心流完全不中断。
- **智能视图保存（Saved Views）**：
  - 将高频使用的复杂筛选条件（如“待处理高优先级技术债务”或“论文综述文献集”）保存为命名视图，下次点击即可一键重现切片结果。

### 3. 📑 多文档批量打标与建档：十倍提升知识整理效率
> **解决问题**：批量导入资料、重组笔记本或整理课题时，无需机械地逐篇手动修改。

- **思源原生文档树右键直达**：
  - 在左侧原生文档树中，支持单选或按住 `Ctrl` / `Shift` 框选多篇文档。
  - 鼠标右键一键点击 **「🏷️ 批量打标签 (X 篇)」** 直达打标窗口，操作顺滑如思源原生功能。
- **递归支持“包含子文档”**：
  - 勾选“包含子文档”选项，自动将选中文档目录下的所有子孙文档全部纳入打标范围，大体量资料库整理只需一步。
- **交互式多源选择器**：
  - 支持按文档标题关键词模糊搜索并点选勾选；
  - 支持按笔记本整组载入；
  - 支持手动批量粘贴文档 ID。
  - 系统内置严格的安全去重机制，确保打标过程绝对安全可靠。

---

### 4. 🩺 标签健康体检与自动化治理：告别“标签债务”
> **解决问题**：个人知识库越用越乱，同义词混杂、大小写不一、临时孤儿标签泛滥。

- **100 分制健康度评分仪表盘**：
  - 一键对全库标签资产进行全景扫描，直观呈现当前知识库的结构健康度与规范指数。
- **四大亚健康问题智能诊断**：
  - ⚠️ **大小写与排版冲突识别**：自动揪出 `Prompt` 与 `prompt`、`Vue-Router` 与 `vue_router` 等同义分裂标签；
  - 🔤 **标点与相似变体检测**：智能识别带有不同连字符、下划线及相似词缀的冗余变体；
  - 🧹 **低频碎片与零引用孤儿标签**：快速找出仅使用过 1 次的边缘临时标签，以及因正文删除而残留的 0 引用标签；
  - 🚫 **异常与不规范符号过滤**：精准识别无语义符号与格式错误的脏标签。
- **一键合并规范化并“沉淀为别名”**：
  - 合并冲突标签时，可一键勾选“合并后将原名沉淀为别名”；
  - 既将全库笔记统一到标准标签名下，又保留了历史输入习惯，以后输入旧习惯词依然能够秒搜定位！

---

### 5. 🔗 双链引用智能识别转标签 (Ref to Tag Promotion)
> **解决问题**：打破“双向链接”与“标签体系”之间的壁垒，让微观引用自动融入宏观分类。

- **智能跨层级扫描**：
  - 自动扫描正文中的块引用与文档双链；
  - 智能对比引用的**显式锚文本**、**被引用文档标题**、**文档命名（Name）**与**多别名（Alias）**，自动寻找标签库中的同名标准标签。
- **一键采纳打标**：
  - 详细标识引用的识别来源（如 `[命名]`、`[别名]`、`[标题]`、`[引用]`）；
  - 支持单篇当前文档诊断与全库引用大体检，勾选后一键批量采纳，让散落在正文中的优质双链概念瞬间沉淀为可多维筛选的标签资产。

### 6. 🕸️ 认知图谱与关联网络：发现潜在灵感
> **解决问题**：发掘看似无关的主题之间频繁共现的深层联系，激发写作与思考灵感。

- **共现权重与 Jaccard 相似度算法**：
  - 科学计算哪些标签经常在同一个文档或段落中相伴出现，绘制动态概念网络图谱。
- **聚焦核心话题与伴生标签**：
  - 点击任意标签，即刻突出显示与之关联度最高的伴随主题，洞察自己的知识关注焦点。
- **从关联洞察到一键沉淀标签组**：
  - 发现高频共现的多元标签组合后，可**一键将关联组合“保存为常用标签组”**，直接闭环到日常写作打标流程中。

---

### 7. 🎨 标签样式定制与视觉编码 (Tag Styler)
> **解决问题**：正文中所有标签千篇一律全是单调灰色/蓝底，无法区分紧急度、领域与状态。

- **双主题 8 组精调色盘**：
  - 内置科技蔚蓝、薄荷翠绿、琥珀亮金、玫瑰艳红、青空苍蓝、紫晶罗兰、暖杏暖橘与石板典雅灰；
  - 基于 **WCAG AA 4.5:1+** 工业级护眼对比度规范精调，无论日间浅色模式还是夜间深色模式，绝不产生刺眼反光或看不清的问题。
- **专属 Emoji 符号加速认知**：
  - 支持为标签配置前缀 Emoji（如 `#灵感#` 搭配 💡，`#待办#` 搭配 📌，`#复盘#` 搭配 🎯）；
  - 编辑器正文自动渲染为精美胶囊药丸，无需阅读文字，扫视一眼即可领会段落含义。
- **样式一键重置，保留别名资产**：
  - 想要还原默认样式时，点击重置即可干净卸载色彩，但完好保留已配置的 Emoji 图标与拼音别名字典。
- **纯粹的零数据污染**：
  - 样式通过合法的 CSS 规则与实时 DOM 装饰器动态注入，**不修改笔记文件的真实底层文本**，停用插件绝不产生任何垃圾数据！

---

### 8. 📄 标签一键升格为实体文档 (Tag to Doc)
> **解决问题**：某个标签下的素材已经积累了数十条，急需沉淀为主题主控页（MOC）。

- 点击标签右键菜单的 **「升格为文档」**；
- 插件会自动在指定笔记本中创建同名聚合文档；
- 自动生成**实时动态 SQL 嵌入块**（实时同步最新打标内容）以及**历史引用快照**，快速从发散碎片构建结构化主题知识库。

## 🚀 30 秒快速上手指南

### 1. 唤起工作台
* **顶栏图标**：点击思源笔记顶部导航栏中的 `标签管家` 专属图标；
* **快捷按键**：按下全局快捷键 `Alt + Shift + T`（macOS 用户按 `⌥ + ⇧ + T`）随时展开/收起侧栏抽屉。

### 2. 新手推荐三步工作流

```
第一步：全面体检 ───────────────> 第二步：日常沉浸使用 ───────────────> 第三步：模块化提效
[健康治理] 一键合并大小写冲突    [资产树/筛选] 拼音盲打检索与布尔切片    [标签组/右键] 批量打标与常用套件
```

1. **第一步 · 整理历史包袱**：
   - 切换到 **「健康治理」** 面板，点击开始全景体检；
   - 优先查看“大小写与排版冲突”，点击“一键合并规范化”，勾选沉淀为别名，秒级消灭历史碎片。
2. **第二步 · 享受沉浸检索**：
   - 写作或阅读时需要查阅资料，按 `Alt+Shift+T` 呼出侧栏；
   - 输入拼音缩写（如 `js` 或 `ts`）即刻找到标签；
   - 点击 `🔍` 图标将标签加入多维筛选，点选 `AND` / `NOT` 获得干净卡片流，点击卡片直接在主窗口平滑定位。
3. **第三步 · 建立高频打标套件**：
   - 在「标签树」面板顶部展开 **「常用标签组」**，为自己的高频场景（如工作周报、读书笔记、项目复盘）创建预设组合；
   - 以后写完同类文档，只需在侧栏点击一次“套用”，文档分类自动搞定！

## 🔒 隐私与数据安全承诺

- **100% 本地运行**：所有拼音计算、SQL 查询、健康体检与图谱分析均在思源笔记本地客户端内核中完成，绝不向任何外部服务器发送您的笔记数据；
- **零脏数据侵入**：
  - 标签样式采用纯 CSS 规则与 DOM 动态装饰，停用插件后不会在 Markdown 源文件中残留任何自定义属性标记；
  - 批量打标与标签组套用均写入思源标准的文档属性（IAL），绝不改动正文结构与版面排版；
- **操作安全兜底**：标签合并与批量操作均内置二次安全确认与防重校验，守护您的知识资产万无一失。
