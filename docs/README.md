## 核心设计规范速查

* **图标规范**：坚决避免使用系统原生彩色 Emoji 充当操作按钮；所有线性图标必须显式在 `<svg>` 上声明 `style="fill:none!important; stroke:currentColor; stroke-width:1.75;"`，彻底规避思源全局 CSS 对 `svg` 的 `fill` 污染。
* **色彩规范**：严格适配思源亮色与暗色模式；所有文字与背景色彩的对比度必须达到 WCAG 2.1 AA 级（对比度 ≥ 4.5:1）以上，严禁在暗黑模式下产生高亮白光斑。
* **交互规范**：操作按钮优先采用“直观线框图标 + 即时微型 Tooltip (150ms 延迟淡入)”呈现；全景树单行避免多按钮水平并排，遵循渐进式暴露原则。
