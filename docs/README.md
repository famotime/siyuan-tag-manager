## 设计核心准则

1. **零侵入与强兼容**：不依赖对思源笔记内核源码的破坏性修改，完全基于公开 Kernel REST API、SQL 查询引擎及 Protyle 前端事件总线实现。
2. **体验轻量与防打断**：杜绝点击标签粗暴弹出全局搜索窗口的断层交互，提供就地即时流式卡片预览与多维布尔筛选（AND / OR / NOT）。
3. **资产化管理与健康治理**：从“被动记录”转向“主动治理”，解决大小写割裂（如 `Prompt` 与 `prompt`）、标签碎片化合并、层级重构与孤儿清理问题。
4. **认知网络与图谱洞察**：引入标签共现网络、生命周期热力与视觉色彩系统，让标签真正成为跨笔记本、跨层级的网状知识连接器。
